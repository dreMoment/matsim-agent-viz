Visualise a run

Watch the agents of a MATSim run move over a 3D map, or explore the run in a 3D world.

Your run stays on this computer. The files are read in this browser tab and never uploaded: there is no server to send them to. Only map tiles and, for trains and walkers, OpenStreetMap paths by tile are downloaded.

Off: trains and trams use the run's own links and walkers move in straight lines, with no download.
Fewer agents make the page smaller and quicker to open (Zurich 10% run, 10% shown: about 34 MB). The build still reads every event, so big runs take a while whatever you pick (reading a Zurich 10% run takes about 40 s).
The run doesn't give a coordinate system this tool can use. Type an EPSG code (e.g. EPSG:25832) or a proj string, then build again.
